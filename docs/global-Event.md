The global [`Event`](https://developer.mozilla.org/en-US/docs/Web/API/Event) interface, as defined in Web specifications. It represents an event which takes place on an [`EventTarget`](global-EventTarget).

---

# Reference

## Constructor

### `Event()`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/Event).

Creates a new `Event` object.

```ts
new Event(type, options?)
```

#### Parameters

**`type`**

A string with the name of the event.

**`options`** (optional)

An optional object with the following properties:

| Name         | Type    | Description                                                                                                 |
| ------------ | ------- | ----------------------------------------------------------------------------------------------------------- |
| `bubbles`    | boolean | Whether the event bubbles. Defaults to `false`.                                                             |
| `cancelable` | boolean | Whether the event can be canceled. Defaults to `false`.                                                     |
| `composed`   | boolean | Whether the event will propagate across the shadow DOM boundary into the standard DOM. Defaults to `false`. |

## Static properties

The following constants are also available as instance properties.

### `Event.NONE`

Returns `0`. No event is currently being processed.

### `Event.CAPTURING_PHASE`

Returns `1`. The event is being propagated through the target's ancestor objects.

### `Event.AT_TARGET`

Returns `2`. The event has arrived at the event's target.

### `Event.BUBBLING_PHASE`

Returns `3`. The event is propagating back up through the target's ancestors in reverse order.

## Instance properties

### `bubbles`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/bubbles).

A boolean indicating whether or not the event bubbles up through the tree.

### `cancelable`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/cancelable).

A boolean indicating whether the event is cancelable.

### `composed`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/composed).

A boolean indicating whether or not the event can bubble across the boundary between the shadow DOM and the regular DOM.

### `currentTarget`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/currentTarget).

A reference to the currently registered target for the event. This is the object to which the event is currently slated to be sent.

### `defaultPrevented`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/defaultPrevented).

A boolean indicating whether or not `preventDefault()` was called on the event.

### `eventPhase`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/eventPhase).

Indicates which phase of the event flow is being processed. It is one of the phase constants described in [Static properties](#static-properties).

### `isTrusted`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/isTrusted).

A boolean indicating whether the event was generated by the platform (`true`) or by a script (`false`).

### `target`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/target).

A reference to the object onto which the event was dispatched.

### `timeStamp`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/timeStamp).

The time at which the event was created (in milliseconds). This value is relative to the same time origin as [`performance.now()`](global-performance).

### `type`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/type).

The name identifying the type of the event.

## Instance methods

### `composedPath()`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/composedPath).

Returns the event's path, an array of the objects on which listeners will be invoked.

### `preventDefault()`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault).

Cancels the event (if it is cancelable).

### `stopImmediatePropagation()`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/stopImmediatePropagation).

For this particular event, prevents all other listeners from being called. This includes listeners attached to the same element as well as those attached to elements that will be traversed later.

### `stopPropagation()`

See [documentation in MDN](https://developer.mozilla.org/en-US/docs/Web/API/Event/stopPropagation).

Stops the propagation of the event further along in the tree.
