title: Performance
---

The global [`Performance`](https://developer.mozilla.org/en-US/docs/Web/API/Performance) class, as defined in Web specifications. It provides access to performance-related information for the running app.

The global [`performance`](global-performance) object is an instance of `Performance`. See its page for the documentation of the available instance properties and methods (including React Native specific extensions).
